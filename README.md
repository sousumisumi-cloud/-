# HamTalk 🐹

ハムスターをモチーフにした、LINE風の静的チャットアプリです。ブラウザだけで遊べます。

## 遊び方

1. このリポジトリのルートでローカルサーバーを起動します。

   ```bash
   npm start
   ```

2. ブラウザで次のURLを開きます。

   ```text
   http://localhost:4173
   ```

3. 左側のハムスター友だちをクリックすると、チャット相手を切り替えられます。
4. 画面下の入力欄にメッセージを書いて送信すると、LINE風の吹き出しで投稿されます。
5. 自分のメッセージを送るたびに「今日のひまわり貯金」が増えます。

## 動作確認

静的ファイルの参照が正しいか確認するには、次を実行します。

```bash
npm run build
```

このアプリは外部パッケージを使っていないため、`npm install`なしでも起動・確認できます。
